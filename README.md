# Sales Sentinel

نظام Flask ثنائي اللغة لتحليل المبيعات اليومية والتنبؤ المبكر باحتمال الانخفاض. أُنشئت هذه النسخة داخل المستودع الحالي بملفات مصدر منظمة وقابلة للقراءة، دون كود مضغوط أو `exec`.

## التشغيل المحلي

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

يفتح التطبيق على `http://127.0.0.1:5000`، وتُبنى قاعدة SQLite تلقائيًا من سلسلة المبيعات اليومية الموثقة عند أول تشغيل.

## حسابات العرض

- `admin` / `Admin@2026!`
- `analyst` / `Analyst@2026!`

## النشر

يدعم Vercel عبر `vercel.json` و`api/index.py`. تستخدم نسخة Vercel قاعدة SQLite مؤقتة داخل `/tmp`، لذلك بيانات العرض تُعاد تهيئتها عند بدء بيئة تشغيل جديدة.

## المصدر

تغطي البيانات اليومية الفترة من يوليو إلى أكتوبر 2023، مع توثيق القيود وأن النموذج أداة دعم قرار Pilot وليست ضمانًا للنتائج.
